# Satyam Holidays 🌍✈️

A professional, fully-responsive tourism website for **Satyam Holidays** — crafted to showcase tour packages, destinations and services to travellers worldwide.

## Pages

| Page | File | Description |
|---|---|---|
| Home | `index.html` | Hero, search bar, popular destinations, featured packages, gallery, testimonials |
| About Us | `about.html` | Company story, values, team, stats |
| Tour Packages | `packages.html` | All packages with category tabs and filter bar |
| Contact | `contact.html` | Enquiry form, contact details, map embed, FAQ |

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, grid, flexbox, animations
- **Vanilla JavaScript** — scroll reveal, tab filters, mobile menu, counter animation
- [Font Awesome 6](https://fontawesome.com/) — icons
- [Google Fonts – Poppins](https://fonts.google.com/specimen/Poppins)
- [Unsplash](https://unsplash.com/) — high-quality travel photography

## Features

- ✅ Fully responsive (mobile-first)
- ✅ Sticky navbar with scroll-shrink effect
- ✅ Full-screen hero with search bar
- ✅ Animated statistics counters
- ✅ Filterable tour packages (tab + category)
- ✅ Scroll-reveal animations
- ✅ Marquee trust bar
- ✅ Photo gallery strip
- ✅ Testimonials section
- ✅ Contact form with success feedback
- ✅ Google Maps embed
- ✅ FAQ accordion
- ✅ Scroll-to-top button
- ✅ Footer with social links

## Getting Started

Open `index.html` in any modern browser — no build step required.

```bash
# Optional: serve locally
npx serve .
```
